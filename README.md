# DevNexa AI

DevNexa AI is an AI-powered agentic software engineering platform
designed to understand, analyze, test, and modify software repositories.

## Core Technologies

- Next.js
- TypeScript
- Python
- FastAPI
- Large Language Models
- RAG
- AI Agents
- Qdrant
- PostgreSQL
- Redis
- Docker
- GitHub API
- Langfuse

## Planned Capabilities

- GitHub repository integration
- Code-aware RAG
- AI-powered code analysis
- Agentic workflows
- Code search
- Automated testing
- Code change proposals
- Docker-based code execution
- GitHub pull requests
- LLM evaluation and observability
